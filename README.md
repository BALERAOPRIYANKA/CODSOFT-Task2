## Project Overview

This project is a modern and responsive personal portfolio website created using HTML and CSS.  
The website showcases personal information, skills, projects, and contact section with an attractive UI design.

## Features

- Responsive Design
- Modern User Interface
- Animated Sections
- Skills Progress Bars
- Project Cards
- Contact Section
- Smooth Hover Effects
- Mobile Friendly Layout

- CSS3
- Google Fonts
- Flexbox
- CSS Animations
